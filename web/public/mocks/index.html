Four directions for IPO Watch

Same data, four different visual languages. Pick the one closest to what you want, or react against the parts that miss.

  1. 01
    Almanac — serif catalog, considered scale
    One serif family, dramatic display sizes, specifications-style tables, one muted accent. Closest to a Patek Philippe / horological catalog or a David Chipperfield monograph. Numbers are the protagonist via scale, not decoration.
  2. 02
    Dashboard — sans-serif fintech portal
    Inter sans throughout, cards with subtle borders, filter chips at top, positive/negative color, tabbed table, real charts. Closest to Tickertape, Tijori, Stripe — functional, dense, colored.
  3. 03
    Editorial — mixed type, magazine lead
    Source Serif for headlines + Inter for data and body. Big italic lead, multi-column secondaries, one warm accent used very sparingly. Closest to Bloomberg Businessweek online or a serious financial weekly.
  4. 04
    Terminal — dense data product, mono numbers
    Inter for prose + JetBrains Mono for every number, near-monochrome, dense data tables with sortable columns, real charts with axes. Closest to a refined Bloomberg Terminal — utility-first, every pixel earning its place.
